# Benchmarks

The published tables on this page are generated by

```bash
uv run --group bench python -m tools.qkdev bench run --suite all
uv run --group bench python -m tools.qkdev bench report --in results/bench/<file>.json
```

on the reference machine (an Intel Core i9-14900K under WSL2; spec P-06, D-11). That run is
scheduled for after 2026-11-29: until then two multi-week data captures share the machine,
and the owner's rule is that no published benchmark runs while they are active. This page is
then regenerated in full by `bench report`, losses included.

What the harness measures (FR-24 to FR-26):

- **micro**: every Must kernel and the rolling median against pure Python, NumPy (cumulative
  sums, `sliding_window_view`), pandas, Numba (warm, compile time reported separately),
  Polars and bottleneck, at n = 1e3, 1e5 and 1e7 and windows 20, 252 and 2,520, contiguous
  and stride-2 inputs. Every comparator's output is checked against qkern (rtol 1e-9) before
  it is timed. All comparators run single-threaded.
- **overhead**: one streaming `update()` call and batch calls on 1, 10 and 100 elements.
- **threads**: 1, 2, 4 and 8 Python threads each running a kernel on its own 1e7-element
  array, with the GIL released and with release forced off.
- **real**: trade log returns from the owner's crypto recorder (`QKERN_REAL_DATA_DIR`),
  aggregate timings only.

Every run appends a row to `results/bench/bench_log.csv`, the honest count of runs.
